# Пошаговый туториал: Утилита копирования файлов

Этот туториал поможет вам самостоятельно реализовать функцию `Copy` от самых базовых концепций до полного решения.

## 📋 Задача (кратко)

Реализовать функцию `Copy(fromPath, toPath string, offset, limit int64) error`, которая:
- Копирует файл из `fromPath` в `toPath`
- Начинает чтение с байта `offset`
- Копирует максимум `limit` байт (если 0 - весь файл)
- Выводит прогресс в процентах
- Возвращает ошибки для невалидных ситуаций

## 🎓 Итоговые вопросы для понимания

1. **Почему мы используем `io.CopyN`, а не просто читаем в буфер и пишем?**
   - Ответ: `io.CopyN` эффективно работает с любыми размерами данных, автоматически использует буферизацию, и код получается проще.

2. **Что происходит, если во время копирования произойдет ошибка?**
   - Ответ: `io.CopyN` вернет ошибку, мы должны ее обработать и вернуть из функции. Файлы закроются через `defer`.

3. **Почему `limit = 0` означает "копировать все"?**
   - Ответ: Это удобное соглашение. Когда limit не задан (0), это означает "без ограничений" - копируем до конца файла.

4. **Зачем нужен Seek перед копированием?**
   - Ответ: Файл открывается на позиции 0. Чтобы начать читать с offset, нужно "перепрыгнуть" туда через Seek.
