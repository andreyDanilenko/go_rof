# 🎓 Руководство по изучению: Утилита копирования файлов

Это руководство поможет вам самостоятельно разобраться с задачей и написать решение.

## 📚 Структура материалов

У вас есть 4 файла для изучения:

1. **LEARNING_GUIDE.md** (этот файл) - навигация и план обучения
2. **TUTORIAL.md** - пошаговый туториал от простого к сложному
3. **EXERCISES.md** - практические упражнения для закрепления
4. **CHEATSHEET.md** - быстрая шпаргалка с примерами кода

---

## 🚀 План обучения (рекомендуемый порядок)

### Этап 1: Подготовка (15 минут)

1. ✅ Прочитайте `README.md` - поймите задачу
2. ✅ Посмотрите на тесты в `test.sh` - поймите ожидаемое поведение
3. ✅ Откройте `copy.go` - посмотрите на структуру функции

**Цель**: Понять, ЧТО нужно сделать, но пока не КАК.

---

### Этап 2: Теоретическая подготовка (30-45 минут)

1. ✅ Прочитайте **TUTORIAL.md** полностью
   - Не спешите, читайте внимательно
   - Останавливайтесь на вопросах для размышления
   - Постарайтесь ответить на них самостоятельно

2. ✅ Выполните упражнения из **EXERCISES.md**
   - Начните с упражнений 1-3 (анализ и понимание)
   - Затем упражнения 4-6 (код и логика)
   - Не переходите дальше, пока не выполните базовые

**Цель**: Понять концепции и логику решения БЕЗ написания кода.

---

### Этап 3: Практическая реализация (пошагово)

#### Шаг 3.1: Откройте файл (5 минут)

Следуйте **Шагу 1** из TUTORIAL.md:
- Откройте файл для чтения
- Закройте его через defer
- Проверьте, что работает

**Проверка**: Код компилируется без ошибок.

---

#### Шаг 3.2: Получите размер файла (5 минут)

Следуйте **Шагу 2** из TUTORIAL.md:
- Получите FileInfo
- Получите размер
- Выведите в консоль для проверки

**Проверка**: Видите размер файла в консоли.

---

#### Шаг 3.3: Добавьте валидацию offset (10 минут)

Следуйте **Шагу 3** из TUTORIAL.md:
- Проверьте offset
- Верните ошибку если offset >= размер

**Проверка**: 
```go
// Напишите простой тест:
err := Copy("testdata/input.txt", "out.txt", 10000, 0)
if err != ErrOffsetExceedsFileSize {
    t.Error("должна быть ошибка!")
}
```

---

#### Шаг 3.4: Реализуйте Seek (10 минут)

Следуйте **Шагу 4** из TUTORIAL.md:
- Вызовите Seek с offset
- Проверьте ошибку
- Проверьте позицию

**Проверка**: После Seek позиция должна быть равна offset.

---

#### Шаг 3.5: Вычислите размер копирования (15 минут)

Следуйте **Шагу 5** из TUTORIAL.md:
- Вычислите остаток файла
- Обработайте limit = 0
- Обработайте limit > остатка

**Проверка**: 
- Для разных offset и limit вычисление корректное
- Используйте **Упражнение 5** из EXERCISES.md для проверки

---

#### Шаг 3.6: Создайте файл назначения (5 минут)

Следуйте **Шагу 6** из TUTORIAL.md:
- Создайте файл через os.Create()
- Закройте через defer

**Проверка**: Файл создается успешно.

---

#### Шаг 3.7: Базовое копирование БЕЗ прогресса (15 минут)

Следуйте **Шагу 7** из TUTORIAL.md:
- Используйте io.CopyN
- Проверьте ошибки
- Проверьте результат

**Проверка**: 
- Запустите `go run . -from testdata/input.txt -to out.txt -offset 0 -limit 10`
- Проверьте размер out.txt - должен быть 10 байт
- Сравните содержимое с ожидаемым

---

#### Шаг 3.8: Добавьте проверку unsupported file (10 минут)

Следуйте **Шагу 8** из TUTORIAL.md:
- Проверьте Mode().IsRegular()
- Верните ErrUnsupportedFile если нужно

**Проверка**: Попробуйте скопировать из /dev/urandom (если доступно).

---

#### Шаг 3.9: Добавьте прогресс-бар (20 минут)

Следуйте **Шагу 9** из TUTORIAL.md:
- Установите библиотеку: `go get github.com/cheggaaa/pb/v3`
- Создайте прогресс-бар
- Оберните Reader
- Используйте в CopyN

**Проверка**: При копировании видите прогресс в процентах.

---

#### Шаг 3.10: Проверьте порядок операций (10 минут)

Следуйте **Шагу 10** из TUTORIAL.md:
- Убедитесь, что все операции в правильном порядке
- Смотрите **CHEATSHEET.md** для примера правильного порядка

**Проверка**: Код работает корректно для всех случаев.

---

## 🎯 Чек-лист готовности

Перед тем как считать задание выполненным, проверьте:

### Базовые требования:
- [ ] Функция Copy реализована и компилируется
- [ ] Все проверки (offset, unsupported) работают корректно
- [ ] Прогресс-бар показывает процент выполнения
- [ ] Все тесты из `test.sh` проходят успешно
- [ ] Написаны юнит-тесты (минимум 4-5 тестовых сценариев)

### Качество кода:
- [ ] Код понятный и читаемый
- [ ] Нет утечек ресурсов (все файлы закрыты через defer)
- [ ] Все ошибки обрабатываются корректно
- [ ] Нет "магических чисел" и неочевидных решений
- [ ] Комментарии добавлены там, где логика неочевидна

### Понимание:
- [ ] Можете объяснить, почему операции выполняются в таком порядке
- [ ] Можете объяснить логику вычисления copySize
- [ ] Понимаете, как работает Seek и почему он нужен
- [ ] Понимаете, как работает прогресс-бар

## 💡 Советы по обучению

### ✅ Делайте так:
1. **Работайте пошагово** - не пытайтесь написать всё сразу
2. **Проверяйте каждый шаг** - убедитесь, что он работает перед переходом дальше
3. **Пишите тесты параллельно** - не откладывайте тестирование на потом
4. **Используйте отладку** - добавьте `fmt.Println` для понимания, что происходит
5. **Читайте документацию** - используйте `go doc` для изучения функций

### ❌ Избегайте:
1. **Копировать готовый код** - вы не поймете логику
2. **Пропускать шаги** - каждый шаг важен для понимания
3. **Игнорировать ошибки** - всегда проверяйте возвращаемые ошибки
4. **Откладывать тестирование** - тесты помогут найти проблемы раньше
5. **Бояться экспериментировать** - пробуйте, меняйте, смотрите что происходит

## 🆘 Если застряли

### Проблема: Не понимаю, что делать на шаге X

**Решение**:
1. Перечитайте соответствующий шаг в TUTORIAL.md
2. Посмотрите примеры в CHEATSHEET.md
3. Попробуйте найти ответ в документации Go (`go doc`)

### Проблема: Код не работает, не знаю почему

**Решение**:
1. Добавьте `fmt.Println` для отладки - посмотрите значения переменных
2. Проверьте, что все ошибки обрабатываются
3. Запустите тесты - они покажут, где проблема
4. Посмотрите на примеры в CHEATSHEET.md - сравните с вашим кодом

### Проблема: Не понимаю логику вычисления copySize

**Решение**:
1. Выполните **Упражнение 5** из EXERCISES.md
2. Нарисуйте на бумаге разные сценарии
3. Попробуйте разные значения вручную и посмотрите результат

### Проблема: Не знаю, как написать тест

**Решение**:
1. Посмотрите на **Упражнение 6** в EXERCISES.md
2. Изучите примеры тестов в CHEATSHEET.md
3. Начните с самого простого теста - просто скопировать файл
